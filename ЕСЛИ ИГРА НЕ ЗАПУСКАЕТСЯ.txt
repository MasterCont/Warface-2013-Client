ЕСЛИ ИГРА НЕ ЗАПУСКАЕТСЯ
========================

Запускайте игру через Start.bat — он сам проверяет Windows перед запуском.


Ошибка «Недопустимый образ» / «Ungültiges Bild» / «Bad Image» про CryOnline.dll,
код 0xc0e90002
--------------------------------------------------------------------------------

Причина: защита Windows 11 «Интеллектуальное управление приложениями»
(Smart App Control) не пускает старые файлы игры 2013 года без цифровой подписи.

Что сделать:

1. Снимите со всех файлов игры пометку «скачано из интернета».
   Нажмите Win+X -> «Терминал» и выполните (путь замените на свой):

       Get-ChildItem -Recurse "C:\Games\Warface RU v1.1.1.426 (2013)" | Unblock-File

   Start.bat делает это автоматически при каждом запуске.

2. Если ошибка осталась — выключите Smart App Control:
       Безопасность Windows -> Управление приложениями/браузером ->
       Интеллектуальное управление приложениями -> Выкл.
   English: Windows Security -> App & browser control -> Smart App Control -> Off
   Deutsch: Windows-Sicherheit -> App- & Browsersteuerung -> Intelligente App-Steuerung -> Aus

   ВАЖНО: обратно включить эту функцию нельзя без переустановки Windows.
   Антивирус Microsoft Defender и брандмауэр продолжат работать.

3. Не держите игру в папке «Загрузки» — перенесите её, например, в C:\Games.


Если появилась другая ошибка — пришлите скриншот администратору сервера.
