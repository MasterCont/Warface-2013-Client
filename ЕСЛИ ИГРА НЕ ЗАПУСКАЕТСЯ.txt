ЕСЛИ ИГРА НЕ ЗАПУСКАЕТСЯ
========================

Запускайте игру через лаунчер SubootLauncher.exe (лежит в папке игры) или через
Start.bat — он сам проверяет Windows перед запуском.


Лаунчер SubootLauncher.exe не запускается: щёлкаете — и ничего не происходит
--------------------------------------------------------------------------------

Причина: файл помечен как «скачанный из интернета» (например, из Discord или
Telegram). Перед запуском такого файла Windows показывает окно SmartScreen
«Windows защитила ваш компьютер». На некоторых сборках Windows (особенно
тестовых — Insider) это окно падает, не успев появиться, и Windows молча
отменяет запуск. Лаунчер при этом исправен.

Что сделать:

1. Правой кнопкой по SubootLauncher.exe -> «Свойства».
2. Внизу вкладки «Общие» поставьте галочку «Разблокировать» -> OK.
   English: Properties -> General -> Unblock -> OK
   Deutsch: Eigenschaften -> Allgemein -> Zulassen -> OK
3. Запустите лаунчер снова.

Если галочки нет — нажмите Win+X -> «Терминал» и выполните (путь замените на свой):

       Unblock-File "C:\Games\Warface RU v1.1.1.426 (2013)\SubootLauncher.exe"

Проверьте ещё:
  - Размер SubootLauncher.exe — около 62 МБ. Если файл весит пару сотен КБ,
    это неправильная сборка: попросите у администратора новую.
  - Рядом не должно быть старых SubootLauncher.dll, .deps.json,
    .runtimeconfig.json, .pdb — их можно удалить, нужен только .exe.
  - Нужна 64-битная Windows 10 или 11.

Если не помогло: попросите у администратора файл diagnose.cmd, положите его
рядом с SubootLauncher.exe и запустите. Он создаст рядом файл
suboot-diagnostics.txt — пришлите его администратору. Журнал самого лаунчера:
%APPDATA%\SubootGames\launcher.log (вставьте путь в адресную строку Проводника).


Ошибка «Недопустимый образ» / «Ungültiges Bild» / «Bad Image» про CryOnline.dll,
код 0xc0e90002
--------------------------------------------------------------------------------

Причина: защита Windows 11 «Интеллектуальное управление приложениями»
(Smart App Control) не пускает старые файлы игры 2013 года без цифровой подписи.

Что сделать:

1. Снимите со всех файлов игры пометку «скачано из интернета».
   Нажмите Win+X -> «Терминал» и выполните (путь замените на свой):

       Get-ChildItem -Recurse "C:\Games\Warface RU v1.1.1.426 (2013)" | Unblock-File

   Start.bat делает это автоматически при каждом запуске.

2. Если ошибка осталась — выключите Smart App Control:
       Безопасность Windows -> Управление приложениями/браузером ->
       Интеллектуальное управление приложениями -> Выкл.
   English: Windows Security -> App & browser control -> Smart App Control -> Off
   Deutsch: Windows-Sicherheit -> App- & Browsersteuerung -> Intelligente App-Steuerung -> Aus

   ВАЖНО: обратно включить эту функцию нельзя без переустановки Windows.
   Антивирус Microsoft Defender и брандмауэр продолжат работать.

3. Не держите игру в папке «Загрузки» — перенесите её, например, в C:\Games.


Если появилась другая ошибка — пришлите скриншот администратору сервера.
