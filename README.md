# Warface 2013 — клиент (Suboot Games)

Скрипты и конфигурация клиента Warface RU **1.1.1.426** для сервера `srv1.wf.suboot.pro`.
Игровые файлы (`Bin32Release`, `Engine`, `Game/*.pak`, уровни — около 2,6 ГБ) в репозиторий не входят:
они раздаются с `https://wf.suboot.pro/client/` и будут докачиваться лаунчером.

## Что здесь

| Файл | Назначение |
|---|---|
| `Start.bat` | Запуск игры: вход и регистрация через API (`https://api.wf.suboot.pro`), сохранённая сессия, информация об аккаунте, список серверов |
| `windows-check.cmd` | Проверка Windows перед запуском: снимает пометку «скачано из интернета» (один раз) и предупреждает о Smart App Control |
| `ЕСЛИ ИГРА НЕ ЗАПУСКАЕТСЯ.txt` | Инструкция для игроков |
| `Game/config/autoexec.cfg`, `system.cfg` | Конфигурация клиента. Адрес сервера передаётся при запуске, настроек и пароля dedicated-сервера здесь нет |
| `docs/` | Устройство клиента |

## Установка

1. Скачайте клиент одним архивом: <https://wf.suboot.pro/client/Warface-2013.zip> (~2,7 ГБ) и распакуйте в любую папку.
   Скрипты из этого репозитория в архив уже входят.
2. Запустите `Start.bat`, зарегистрируйтесь или войдите.

## Раздача файлов

| Адрес | Что это |
|---|---|
| `https://wf.suboot.pro/client/Warface-2013.zip` | Весь клиент одним архивом |
| `https://wf.suboot.pro/client/manifest.json` | Список файлов клиента: путь, размер, sha256 (для лаунчера) |
| `https://wf.suboot.pro/client/files/<путь>` | Отдельные файлы (докачка и проверка лаунчером) |

Запуск игры без `Start.bat` (вручную) больше не работает: сервер принимает только одноразовые токены,
которые выдаёт вход по логину и паролю.
